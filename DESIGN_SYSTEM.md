# SwapSkill Design System

Version: 1.0
Project: SwapSkill
Framework: Laravel 13 + Blade + Tailwind CSS v4 + Vite

---

# Overview

SwapSkill is a modern skill exchange platform where users exchange knowledge instead of money.

The UI should always feel:

- Modern
- Professional
- Friendly
- Clean
- Accessible
- Consistent
- Minimal
- Responsive

Avoid visual clutter.
